# 🏛️ Government Hostel Chembur Website

A modern, responsive hostel management and information website built for **Bharat Ratna Dr. Babasaheb Ambedkar Boys Government Hostel, Chembur (Unit 1, 2 & 3)** and **Sant Eknath Backward Class Hostel, Chembur**.

> **Note:** This is an independent student-developed project created for educational and informational purposes. It is not an official government website.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/government-hostel-chembur.git
```

Move into project

```bash
cd government-hostel-chembur
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
ATLASDB_URL=

CLOUDINARY_CLOUD_NAME=

CLOUDINARY_KEY=

CLOUDINARY_SECRET=

SECRET=

PORT=3000
```

Start the server

```bash
npm start
```

For development

```bash
npm run dev
```

Open

```
http://localhost:3000
```
